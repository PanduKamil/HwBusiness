# HwBusiness
# Gudang Project - Inventory Management System

Aplikasi backend berbasis Java yang dirancang untuk mengelola dan melacak stok barang di gudang secara efisien.

## Fitur Utama
- Manajemen data inventaris barang (CRUD).
- Integrasi penyimpanan data lokal secara terstruktur.
- Pengujian endpoint API yang efisien.

## Tech Stack
- **Language:** Java (OOP)
- **Framework:** Javalin
- **Database:** H2 Database
- **Tools:** Postman (API Testing), Git
